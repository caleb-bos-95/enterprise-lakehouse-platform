# Governance

Data governance policies, RBAC models, and trust scoring frameworks.

## Structure

- `policies/` — Data access and retention policy definitions
- `rbac/` — Role-based access control model definitions
- `trust/` — Trust score definitions and quality thresholds

## Governance Philosophy

Governance is treated as a first-class engineering concern — not a post-hoc addition. Every dataset must have an assigned owner, documented lineage, and a defined trust score before it is promoted to Gold.
